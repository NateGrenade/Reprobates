# Reprobates Repository Reading Skill

When you need to find information about an idea, concept, character, location, event, mechanic, or other element of *Reprobates*:

1. First consult `INDEX.md` at the root of the repository.
2. Use the index's keywords and descriptions to identify the file(s) most relevant to the subject.
3. Read the relevant source file(s) before answering or making claims about the subject.
4. If the index points to multiple relevant files, consult them as needed to build an accurate understanding and reconcile their information.
5. Treat repository material as the current source of truth for established *Reprobates* canon. Do not invent missing details to fill gaps.
6. If the available files do not contain enough information to answer confidently, say so rather than presenting speculation as established canon.
7. When a question concerns a broad or complex subject, follow the relevant references from `INDEX.md` rather than assuming that one overview file contains everything.
