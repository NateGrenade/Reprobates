# Reprobates

Automatic backup of Nathan's Obsidian vault for *Reprobates*. Edits happen in Obsidian, so don't edit here; changes made on GitHub can conflict with the vault.

- Start at `Home.md`. Each note's YAML front matter has `status` (canon / provisional / proposal / speculation / rejected) and a one-line `description`.
- `[[Note Name]]` links point to the `.md` file with that name anywhere in the repo. `[[Note#Heading|text]]` points to a heading inside it.
- Don't promote an idea's status (e.g. speculation → canon) without Nathan's say-so.
